# 标准（standard）

## 何时进入本档
- 用户想系统学一个知识点或一个小节：「从头讲一遍」「帮我学会这块」。
- 用户在某处反复出错，需要定向补漏。
- 复习档答错后回流做「90 秒补讲」。

本档是「学过 → 待复习」的唯一入口。

## 输出结构（零件与顺序）
必需零件（缺任一即判废）：`explain_card` → `quiz_card` → `verdict_card`。
可选零件：`keypoint_card`、`review_card`。
顺序：讲解卡讲一个 chunk → 讲完即问（题卡）→ 判题卡给对错与解析。

## 节奏（追问密度 / 复述 / 出题）
- 追问密度：中。
- 复述：不强制。
- 出题：强制（题卡与判题卡必在签名内）。
一次只推进一个 chunk：讲解、提问、小结各一轮。

## 心理学取向
- 理解与建构、练习与迁移、记忆与巩固。
- 精加工 + 自我解释 + 精细提问；正例与反例成对，靠对比划边界。
- 答错才补讲，答对不啰嗦。

## 结束与回写
- 讲完且自检通过 → 生成 1~3 张复习卡入队，初次到期 = 次日。
- 未自检通过的内容不许入复习队列。
