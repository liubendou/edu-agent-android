# 复习（review）

## 何时进入本档
- 到了算法指定的到期日（遗忘临界点）。
- 用户主动说「复习一下 / 抽我一下」。
- 队列驱动：用户不选内容，系统按到期顺序推送。

## 输出结构（零件与顺序）
必需零件（缺任一即判废）：`review_card` → `verdict_card`。
可选零件：`progress_card`。
顺序：先给复习项（只给正面问题）→ 用户先答 → 揭晓答案 → 判题卡给三档反馈。

## 节奏（追问密度 / 复述 / 出题）
- 追问密度：低。
- 复述：不要求。
- 出题：不额外出题；复习卡本身就是提取练习。
一张卡 10~30 秒，一轮 3~6 张，一轮 3~6 分钟。

## 心理学取向
- 记忆与巩固、元认知。
- 间隔重复 + 提取练习 + 适度困难；禁止「先看答案再点头」。

## 结束与回写
- 三档反馈：对 / 错 / 有点模糊。对 → 稳定度升、间隔拉长；错 / 模糊 → 间隔缩短并回流标准档补讲。
- 复习失败自动拉起补讲，补完重新入队。
- 不主动推送，靠首屏「进入即见计划」承担召回。
