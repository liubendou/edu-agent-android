## 3 约定插件（`build-logic`，本步自建）

脚手架模板**实际不含** `build-logic`（`03-工具箱\脚手架\说明.md` 的描述与仓库内容不符），故本步按 Google 约定插件规范自建 composite build：`build-logic/`（`includeBuild`）/ `build-logic/convention/`。

**实际注册的插件 id（逐字，后续步骤统一按此引用）**：

| 插件 id | 实现类 | 作用 |
|---|---|---|
| `eduagent.android.application` | `AndroidApplicationConventionPlugin` | `com.android.application` + `compileSdk 37` + `minSdk 29` + `targetSdk 36` + Java/Kotlin 17 + release 不混淆 |
| `eduagent.android.library` | `AndroidLibraryConventionPlugin` | `com.android.library` + `compileSdk 37` + `minSdk 29` + Java/Kotlin 17 + release 不混淆 |
| `eduagent.android.compose` | `AndroidComposeConventionPlugin` | `org.jetbrains.kotlin.plugin.compose` + 打开 `buildFeatures.compose`（须排在 application/library 之后） |
| `eduagent.android.hilt` | `AndroidHiltConventionPlugin` | `com.google.dagger.hilt.android` + `com.google.devtools.ksp`（注解处理统一走 KSP2） |
| `eduagent.kotlin.jvm` | `KotlinJvmConventionPlugin` | `org.jetbrains.kotlin.jvm` + Java/Kotlin 目标 17 |

- 约定插件**不声明版本**；版本唯一来源是 `gradle/libs.versions.toml`（冻结版）。AGP/KGP/Compose/KSP/Hilt 在根 `build.gradle.kts` 以 `apply false` 登记进插件解析。
- 模块统一写法：`plugins { alias(libs.plugins.eduagent.android.library) }`。
- 插件别名在版本目录中登记于 `[plugins]` 段（`version = "unspecified"`，由 included build 解析）。

## 7 契约 §1 的书面修订记录（本步例外，需你同步到控制台）

**修订项**：契约 §1 SDK 冻结值 `compileSdk 36` → **37**（`targetSdk 36`、`minSdk 29` 不变）。

**四项式**：

| 项 | 内容 |
|---|---|
| 红线/条目 ID | 契约 §1（SDK 冻结）+ §13 D11 |
| 为何必须 | 冻结的库集（BOM `2026.09.00` → Compose `1.12.1` 全家、`material3-adaptive 1.3.0`、`vico 3.3.1`、`core-ktx 1.19.1`、`lifecycle-*-compose 2.11.0` 共 19 个 AAR）的 AAR 元数据**硬性要求** `minCompileSdk ≥ 37`，AGP 编译期直接报错、**无开关可绕** |

| 批准人 | 用户（2026-10-18，第 2 步汇报后选「选项 A：最小改动」） |

**佐证**：官方脚手架（同一套版本：AGP 9.4.1 / BOM 2026.09.00 / Kotlin 2.4.20 / KSP 2.3.12 / Hilt 2.60.1 / core 1.19.1 / lifecycle 2.11.0）用的是 `compileSdk = 37`、`targetSdk = 37`，即契约把两个互斥的值同时冻结了。
