## 5 红线落实举证

### 5.1 R-T10（payload 无动效字段）
`NoMotionFieldTest` 以反射遍历 16 个 payload 类型及其可达字段类型，断言不出现任何 `duration/delay/easing/spring/curve/…` 类成员；动效一律走 `:core:design` 的 `MotionTokens`/`MotionLevel`，零件只提供 `Modifier`。

### 5.2 §4 硬规则「answer 判分前不下发」
`QuizCardPayload(stem, kind, options, explain)` **无 `answer` 字段**（类型系统强制）；`VerdictCardPayload(result, userAnswer, answer, explain)` 才持有。`QuizVerdictPairTest` 用**专属哨兵串**（`PAIR_VERDICT_ANSWER_UNIQUE`）断言 quiz 单独渲染时 UI 树中检索不到该串。

### 5.3 R-C1 / R-C2（来源不得编造）
`ToolCardPart`：`val sourced = payload.results.filter { !it.source.isNullOrBlank() }`，逐项渲染仅取 `sourced`。样品信封 `PartSamples` 的 `tool_card` **故意**含一条 `source = null` 的 `NO_SOURCE_ITEM`；`ToolCardSourceTest` 断言该条不出现在 UI 树。

### 5.4 R-P3 / §7（不空屏、不静默、禁红色报错框）
- 未知 type：`PartHost` 先做 `PartTypes.ALL` 白名单 + `PartFieldCheck.missingFields` 判定 → 命中即走 `UnknownPart`，`LaunchedEffect(type)` 上报 `PartAnalytics.onUnknownPart(type)` 一次，**再降级**为 `PlainTextPart`。`PartRegistryTest` 断言 `foo_card` 不抛异常且埋点恰好一次。
- 字段缺失：同路径降级，`PartFieldAssertTest` 断言不崩。
- `PlainTextPart` 为**纯文本段落**（无红色/无报错框），空文本回退 `part_fallback_empty`。

### 5.5 §8.5 零件入场 / 流式纪律
- `Modifier.partEntrance()`：`Animatable(0f)` + `tween(MotionTokens.baseMs, FastOutSlowInEasing)`，仅写 `graphicsLayer { alpha; translationY }`，**不触发重组/重排**；`local` 档位不允许位移时直接 `return this`；**无缩放弹出**。
- `StreamingText`：每字节拍 `delay(28ms)` 匀速吐字，吐完才回调 `onCompleted`（调用方据此 enable 交互）；minimal 档不逐字、直接全文 + 回调。

- K1.1：`PartRenderTest`×16（可组合、无崩溃、无白屏）+ §4.2 第 1/2 条真机复核（交你执行）。
- V5：入场所用属性均为 `graphicsLayer` 层（不参与测量/布局），已入场零件不重排；demo 页用 `key(restartKey)` 整段重挂载以反复观察。
