## 4 minimal「信息不丢失」举证（V2）

下表 `静态载体` 逐条由 `RecipeMinimalTest` 断言（`MotionSpec.minimal.carriers`）：

## 7 与冻结契约的两处 API 偏差（须你裁决）

冻结契约 `01-契约.md` §8 与任务包 05 §7 给出的逐字签名，在**冻结的 Compose 1.12.1（BOM 2026.09.00）**
上已不存在或被改写。实测（`javap` 解冻结 AAR）：

| # | 契约 / 任务包写法 | 冻结版本实测 | 本步做法 |
|---|---|---|---|
| 1 | §7-B：`val snappy = Spring(stiffness = 380f, dampingRatio = 30f)`；§8.2「用 Compose `Spring(stiffness, dampingRatio)` 原生参数」 | `androidx.compose.animation.core.Spring` 已是**常量对象**（`StiffnessMedium` 等），**无** `Spring(stiffness, dampingRatio)` 可构造形式；可构造的原生弹簧类型是 `SpringSpec<Float>` | 改用 `SpringSpec(stiffness=..., dampingRatio=...)`：同物理参数、同为原生，**未**用 cubic-bezier 近似（§6 禁止项 1 未被触犯）。`MotionTokensTest` 以原生参数逐字比对并交叉核 `motion-tokens.json` |
| 2 | §14.7 / D27：`LocalMotionDurationScale.current == 0f` | Compose 1.12.1 **已移除** `LocalMotionDurationScale`（改由 CoroutineContext 的 `MotionDurationScale` 承载，无公开 CompositionLocal） | 改读其**唯一上游** `Settings.Global.ANIMATOR_DURATION_SCALE == 0f`（Compose 内部 `MotionDurationScaleImpl` 亦监听该键，语义等价）。`MotionLevelTest` 固化读取路径 |

> 两处均为「冻结版本的 API 面变了」，不是数值改写：tokens 数值 120/200/600/800 与 380-30/260-30/260-26
> 全量保留，并已与 `assets/contract/motion-tokens.json` 逐字对齐（`MotionTokensTest` 5 用例机检）。
> 若你判定必须**逐字**符合契约写法，请裁定改契约或改版本 —— 施工方无权自改契约。
